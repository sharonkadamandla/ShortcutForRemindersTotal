# Shortcut for Apple Reminders Total
Shortcut to Calculate the Total in Apple Reminders (Eg: Shopping List)

## What It Does

This Apple Shortcut transforms a standard list in Apple Reminders into a dynamic shopping budget tracker or any calculator you tweak it to.

### Key Features

Automated Price Extraction: Scans reminder titles for dollar amounts or numeric values using Regular Expressions (Regex).

Dynamic Sum Calculation: Calculates the sum total of all uncompleted items in your selected list.

In-List Real-time Update: Automatically updates a target header or subtask line named Total directly inside the Reminders app with the calculated sum (e.g., Total : $167.97).

Background Trigger: Runs seamlessly in the background when closing the Reminders app or triggered via Back Tap or widgets.
